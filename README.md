## 发布到 GitHub Pages

1. 把代码合并到 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. **Source** 选 **Deploy from a branch**；**Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会显示网址，格式是：
   `https://<你的 GitHub 用户名>.github.io/<仓库名>/`
   例如本仓库是 `https://songyutao0408-dot.github.io/math-4a/`。

仓库根目录有 `.nojekyll`，所有路径都是相对路径，放在 `/仓库名/` 子路径下也能正常工作。

**不用服务器也能用**：直接用浏览器打开 `index.html` 文件就能运行（页面用 `#/` 路由，没有 ES module）。
阶段 5 会再提供一个单文件版 `dist/math-island.html`，可以发到手机上离线打开，防止 github.io 在国内打不开。

## 家长：如何对照课本修改内容

所有题目内容都在 `js/units/` 下的单元文件里，和界面代码分开。以第①单元为例，打开 `js/units/u1-big-numbers.js`：

### 改知识卡

找到 `var cards = [ ... ]`，每张卡长这样：

```js
{
  id: 'read', emoji: '🗣️', title: '读数',
  points:   ['要点 1', '要点 2'],      // 要点，一条一行
  examples: ['例子 1', '例子 2'],      // 例子
  pitfall:  '易错提醒'                 // 易错提醒，一句话
}
```

直接改文字即可；要加一张卡就照样子复制一份，`id` 换个不重复的英文名。

### 改题目范围

- **数字位数**：文件开头的 `var LEN = { 1: [5, 8], 2: [7, 10], 3: [9, 12] };`，
  分别是“基础 / 提高 / 挑战”出的数是几位到几位。比如课本只学到十位数，就把 `12` 改成 `10`。
- **某一类题**：每类题是一个 `G.xxx = { skill, levels, gen }`，
  - `levels: [1, 2, 3]` 表示在哪些难度出现，删掉某个数字它就不在那个难度出现；
  - 不想要这类题，把整段 `G.xxx = {...};` 删掉即可；
  - 每段上面的注释写了参数范围。
- **知识点名称**：`var skills = [...]`，这里的名字会显示在题目标签和家长统计里。
- **概念判断题**：`var fixed = [...]`，每条是 `{ skill, prompt, answer: true/false, explanation: [...] }`。
  这是唯一手写答案的地方（概念对错本身就是课本内容）；其他所有题的答案都由代码计算。

改完刷新页面就生效。建议改完跑一下 `node --test tests/*.test.js`，确认没有出现非法的题。

## 设计说明

- **反馈**：答对有小动画和合成音效；第一次答错给一句提示，可以再试；第二次答错显示分步讲解，练习模式下再补一道同类题巩固。不扣分、不满屏红叉。
- **星星**：闯关测验 15 题，一次答对 ≥60% 一星、≥80% 两星、全对三星，保留最高纪录。
- **错题重现**：每道题由 `{单元, 生成器, 随机种子, 难度}` 生成，同样的参数永远得到同一道题，错题本只需保存这几个参数。
- **答案判定宽容**：全角/半角数字、空格、千分位逗号都能识别；“约”等同于“≈”；汉字读法统一规范化后比较（如“一十万”按“十万”算）。
- **存储**：`localStorage`，键名前缀 `mi4a:`，读写都有保护；无痕模式等存不了时也能正常做题，只是不保存。
- **休息提醒**：连续使用 25 分钟弹出温和提醒。
