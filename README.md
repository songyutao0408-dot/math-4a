# 🏝️ 数学岛 · 四年级上册复习闯关

给四年级孩子在手机上复习**人教版（2026 秋新教材）四年级上册数学**的互动网页。
纯静态（HTML + CSS + 原生 JavaScript），零外部依赖，不联网、不收集数据，进度只存在本机浏览器里。

内容唯一依据：[`knowledge-4a.md`](knowledge-4a.md)。

## 功能一览

- **数学岛地图**：9 座小岛（①～⑧ 各单元 + ⑨ 期末大挑战），显示星星和完成度，不强制顺序。
- **每座岛三个标签**：📖 知识卡（左右滑动、标记“我懂了”）· ✏️ 练一练（每轮 10 题，基础/提高/挑战）· 🏆 闯关测验（15 题，≥60% 一星、≥80% 两星、全对三星，保留最高纪录）。
- **像家教一样的反馈**：第一次答错给一句提示、可以再试；第二次答错显示分步讲解，练习时再补一道同类题。不扣分、不满屏红叉。
- **动手互动**：数位顺序表拖数字卡、分级线、四舍五入先点“看哪一位”、点选拼读、算盘；竖式乘法网格（“检查这一步”只标出错的那一格）；线段图、时间轴、两家店对比表；SVG 量角器读数和画角、角和四边形拖进筐分类、钟面角、三角尺拼角；点出最短线段、梯形的底和腰；条形统计图读图、拖动直条补全；藏宝图按指令走、绕开石头；鸡兔同笼列表法互动表、假设法分步填空、画图法。
- **错题本**：自动收集，能原样重现，按单元筛选，“重练错题”连续答对 2 次自动移出。
- **每日一练**：每天 10 题，优先错题和正确率最低的知识点。
- **奖励页**：19 枚徽章（大数小达人、量角高手、竖式不粗心、连对 10 题、连续学习 3 天……），已得、未得都展示。
- **家长页**（设置 → 家长页，先答一道三位数乘两位数的笔算题）：各单元/知识点正确率、累计做题数、最近 7 天学习天数、高频错题；导出数据（JSON）、清空全部数据（二次确认）。
- **设置**：音效开关、读题（浏览器支持才显示）、字号（标准/大）。
- **口算挑战**（③单元练一练页）：可选的 60 秒限时口算；平时做题都不计时。
- 连续使用 25 分钟弹出温和的休息提醒。

## 发布到 GitHub Pages

1. 把代码合并到 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. **Source** 选 **Deploy from a branch**；**Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会显示网址，格式是 `https://<GitHub 用户名>.github.io/<仓库名>/`，
   本仓库就是 `https://songyutao0408-dot.github.io/math-4a/`。

仓库根目录有 `.nojekyll`，所有路径都是相对路径，放在 `/仓库名/` 子路径下也能正常工作。

### 添加到主屏幕（PWA，离线可用）

用手机浏览器打开上面的网址：
- iPhone Safari：点底部“分享” → “添加到主屏幕”。
- 安卓 Chrome：菜单 → “添加到主屏幕 / 安装应用”。

打开过一次之后，没有网络也能用（`sw.js` 会缓存全部文件，作用域就是仓库所在的子路径）。

### 备用方案：单文件离线版

如果 github.io 在国内打不开，用 [`dist/math-island.html`](dist/math-island.html)：
这是一个把所有 CSS 和 JS 都内联进去的独立文件，直接发到手机上（微信“文件传输助手”、AirDrop 等），用浏览器打开就能离线使用。

> 在微信里直接点开文件时，部分手机会用微信内置浏览器打开，大部分功能可用；如果遇到不能保存进度，可以点右上角“用浏览器打开”。

## 本地开发与测试

不需要安装任何依赖，只要有 Node.js（18 以上）：

```bash
node --test tests/*.test.js
```

每个生成器每个难度默认随机出 1000 题检查；想跑得更狠一点：

```bash
RUNS=5000 node --test tests/*.test.js
```

**改了任何代码或内容之后，请运行一次打包脚本**（更新单文件版和 PWA 缓存清单；不运行的话测试会提醒你）：

```bash
node scripts/bundle.js
```

手动检查清单见 [`tests/manual-checklist.md`](tests/manual-checklist.md)。

```
js/widgets/             互动组件：拖拽、数位顺序表、大数（分级/四舍五入/算盘）、竖式乘法、线段图、几何（量角器等）、统计图、藏宝图、鸡兔同笼

sw.js、manifest.json、icons/   PWA

```

## 家长：如何对照课本修改内容

所有题目内容都在 `js/units/` 下，和界面代码分开：

| 小岛 | 文件 |
|---|---|
| ① 大数的认识 | `js/units/u1-big-numbers.js` |
| ② 角的度量 | `js/units/u2-angles.js` |
| ③ 多位数乘两位数 | `js/units/u3-multiply.js` |
| ④ 加法模型和乘法模型 | `js/units/u4-models.js` |
| ⑤ 平行四边形和梯形 | `js/units/u5-quadrilaterals.js` |
| ⑥ 条形统计图 | `js/units/u6-bar-charts.js` |
| ⑦ 寻找宝藏 | `js/units/u7-treasure.js` |
| ⑧ 鸡兔同笼 | `js/units/u8-chicken-rabbit.js` |
| ⑨ 期末大挑战 | `js/units/u9-final.js`（`mix` 字段决定从哪些岛混合出题） |

每个文件结构一样：

### 改知识卡

找到 `var cards = [ ... ]`，每张卡长这样：

```js
{
  id: 'read', emoji: '🗣️', title: '读数',
  points:   ['要点 1', '要点 2'],      // 要点，一条一行
  examples: ['例子 1', '例子 2'],      // 例子
  pitfall:  '易错提醒'                 // 易错提醒，一句话
}
```

直接改文字即可；加一张卡就照样子复制一份，`id` 换个不重复的英文名。

### 改题目范围

- 每一类题是一段 `G.xxx = { skill, levels, weight, gen }`：
  - `levels: [1, 2, 3]`：在哪些难度出现（1 基础、2 提高、3 挑战），删掉某个数字它就不在那个难度出现；
  - `weight`：出现的多少（默认 1，越大越常出）；
  - 不想要这类题，把整段 `G.xxx = {...};` 删掉；
  - 每段上面的注释写了参数范围，`gen` 里的 `rng.int(最小, 最大)` 就是数字范围。
- ①单元的数字位数：文件开头 `var LEN = { 1: [5, 8], 2: [7, 10], 3: [9, 12] };`（基础/提高/挑战出几位到几位的数）。
- 知识点名称：`var skills = [...]`，会显示在题目标签和家长页统计里。
- 概念判断题：`var fixed = [...]`，每条是 `{ skill, prompt, answer: true/false, explanation: [...] }`。
  这是唯一手写答案的地方（概念对错本身就是课本内容）；其他所有题的答案都由代码计算。

改完刷新页面就生效；建议再跑 `node --test tests/*.test.js` 检查有没有出现非法的题，然后 `node scripts/bundle.js`。

## 设计说明

- **错题重现**：每道题由 `{单元, 生成器, 随机种子, 难度}` 生成，同样的参数永远得到同一道题，错题本只存这几个参数。
- **答案判定宽容**：全角/半角数字、空格、千分位逗号都能识别；“约”等同于“≈”；汉字读法统一规范化后比较（如“一十万”按“十万”算）；角度允许误差（读量角器 ±1°，画角 ±2°）。
- **存储**：`localStorage`，键名前缀 `mi4a:`，读写都有保护；无痕模式等存不了时也能正常做题，只是不保存。
- **兼容**：普通 `<script>`，不用 `?.`、`??` 等较新语法（照顾旧版微信内核）；拖拽用 Pointer Events，所有拖拽都有“点一下再点一下”的替代操作。

## 需要家长确认 / 以后可调整的地方

1. **尺规作图**：新版教材有“尺规作图画平行线、画长方形”，但知识清单里没写具体步骤，所以⑤单元没有出尺规作图的题，只出了“一合、二靠、三移、四画”的三角尺画法。课本步骤确认后可以加。
2. **数字范围**：①单元最大到 12 位数（千亿位）；③单元竖式最大是三位数乘两位数；④单元除法只用一位数除数（除数是两位数的除法在四下）。和课本不一致可以按上面的方法改。
3. **固定概念题**：每个单元的 `fixed` 里有少量手写答案的判断题（如“0 是最小的自然数”），请对照课本说法看一下。
4. **徽章条件**：在 `js/core/badges.js` 里，每枚徽章一行，可以改名字和条件。
