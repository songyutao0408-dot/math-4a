# 手动检查清单

在真机（或浏览器开发者工具的手机模式，宽度 375px）上逐项检查。每个阶段交付前过一遍。

建议设备：iPhone Safari、安卓 Chrome、**微信内置浏览器**（把链接发到微信里点开）。

## 全局

- [ ] 所有页面在 375px 宽下**没有横向滚动**（左右拖不动）
- [ ] 深色模式下（手机设置里打开深色）所有文字都看得清，按钮边界清楚
- [ ] 设置里把字号调成“大”，页面不乱、不出现横向滚动
- [ ] 刘海屏 / 底部横条不遮挡顶部标题和底部导航
- [ ] 打开系统“减少动态效果”后，动画基本消失，功能正常
- [ ] 断网后刷新（已打开过的页面）或直接打开本地 `index.html`，能正常使用
- [ ] 无痕模式打开：能做题；设置页提示“不能保存进度”
- [ ] 长数字没有被 iOS 识别成电话号码（不变蓝、不能拨号）

## 首页地图

- [ ] 9 座岛都显示，按 ①～⑨ 弯弯曲曲排下来，名字不被遮挡
- [ ] 每座岛显示星星（0～3）和完成度；未完成的岛显示“建设中”，点进去有友好提示
- [ ] 底部导航 5 个按钮都能点，当前页高亮

## 单元页（①大数的认识）

- [ ] 知识卡：左右滑动能翻页，上下滑动页面不会误翻卡；‹ › 按钮可用
- [ ] 点“我懂了”变绿、计数增加，自动翻到下一张；再点一次可以取消
- [ ] 练一练：三个难度能选，下次进来记得上次选的难度
- [ ] “我的知识点”显示每个知识点的正确率
- [ ] 闯关测验：显示最好成绩和得星规则

## 做题

- [ ] **数字键盘**弹出时，不弹系统键盘；题目和空格不被键盘挡住（能滚动看到）
- [ ] 键盘上的“≈ = 万 亿”只在需要的题里出现
- [ ] 多个空的题：点空格可以切换；按“确定”会跳到下一个没填的空
- [ ] **数位顺序表**：在触屏上能把数字卡**拖**进格子；也能“先点卡片再点格子”；选中的卡可以连着放好几格；点格子里的数字能拿走
- [ ] 中间空着没填 0 时，提示“中间空着的数位要写 0 占位哦”
- [ ] **分级线**：点两个数字之间能画线/擦掉，手指点得准
- [ ] **四舍五入**：先点“看哪一位”，点错有提示不扣分；点对后高亮那一位，再出现填空
- [ ] **点选拼读**：点字块拼读法，能撤销、清空
- [ ] **□ 多选**：可以选多个
- [ ] **算盘**：珠子看得清，靠梁的珠子是彩色
- [ ] 💡 提示按钮随时能看提示
- [ ] **竖式乘法**：点格子输入、自动往左移；“检查这一步”只标出错的一格；末尾有 0 的题，0 写在后面
- [ ] **线段图 / 时间轴 / 对比表**：文字不挤、不出框，深色模式看得清
- [ ] **量角器**：内外圈刻度看得清；画角时拖动圆点顺手，± 1° 按钮可用
- [ ] **拖进筐里分类**（角、四边形）：触屏拖得动，也可以点图形再点筐；图形是各种方向摆放的
- [ ] **点线段**（最短线段、梯形的底和腰）：手指点得中
- [ ] **条形统计图**：横着、竖着都正常；复式图有图例；拖直条补图顺手，− + 按钮可用
- [ ] **藏宝图**：方向按钮够大；走出地图、碰到石头有提示；“重来”可用
- [ ] **鸡兔同笼**：列表法表格每调一次多一行；画图法先画 2 只脚，再点动物补脚
- [ ] **口算挑战**：60 秒倒计时，结束显示答对几道、最好成绩

## 反馈流程（每个单元都走一遍）

出题 → 答错 → 看讲解 → 重试 → 进错题本 → 重练移出

- [ ] 第一次答错：底部出现黄色提示卡（一句提示），选错的选项变灰，可以“再试一次”
- [ ] 第二次答错：显示正确答案和分步讲解（第一步、第二步……），不出现大红叉
- [ ] 练一练里讲解之后多出一道“巩固一下”的同类题（进度条总数 +1）
- [ ] 答对：有小星星动画和音效，鼓励语会变化；连对时顶部显示 🔥 连对数
- [ ] 一轮结束：显示一次答对数、该再练的知识点；测验显示星星，新纪录有提示
- [ ] 做题中点 ✕ 离开：弹出确认；确认后回到单元页
- [ ] 做错的题已进入错题本，能按单元筛选
- [ ] 错题本“重练错题”：同一道题连续答对 2 次后从错题本消失
- [ ] 每日一练：10 题，里面有错题本里的题；做完显示“今天已经练完啦”
- [ ] 奖励页：已得徽章是彩色的，未得的是灰色并显示进度；得到新徽章时弹出提示
- [ ] 家长页：要先答对一道三位数乘两位数；统计数字合理；“导出数据”能下载或显示文字；“清空全部数据”要确认两次
- [ ] 设置里“读题”（浏览器支持时才有）：打开后出题会朗读，题目上有 🔊
- [ ] 连续学 25 分钟弹出休息提醒
